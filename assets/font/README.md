# Font

`m6x11.png` is the m6x11 pixel font by Daniel Linssen (managore), https://managore.itch.io/m6x11 (free to use with
attribution). It is the 16 by 6 ASCII sheet (codes 32 to 126, 10 by 14 pixel cells, 11 rows above the baseline) from
the BOK's `Assets/Fontm6x11.png`, converted to white ink on a transparent background so the page can tint it. The page
measures each glyph's width at load, so text is proportional.
